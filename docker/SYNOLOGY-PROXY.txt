# Домофон на Synology + отдельный проект SNI Proxy
#
# SNI Proxy НЕ здесь — см. C:\Cursor_project\sni-proxy
#   на NAS: /volume1/docker/sni-proxy
#
# Связь: общая Docker-сеть sni-net
#   docker network create sni-net
#
# Роутер: 443 → Synology (контейнер sni-proxy)
# edge/coturn слушают внутри sni-net (имена domofon-edge, domofon-coturn)

================================================================================
1) Сеть (один раз)
================================================================================
  docker network create sni-net

================================================================================
2) Домофон (/volume1/docker/domofon/docker)
================================================================================
  docker compose up -d --build
  # edge + coturn автоматически в sni-net

================================================================================
3) SNI Proxy (/volume1/docker/sni-proxy) — отдельно
================================================================================
  см. README.txt в проекте sni-proxy
  docker compose up -d

================================================================================
4) DSM
================================================================================
  Отключить Reverse Proxy на :443 (ASIC Watchdog и др.)
  DSM UI: https://IP:5001
  PWA идёт через sni-proxy → domofon-edge → 192.168.0.34:8002

================================================================================
5) Приложение
================================================================================
